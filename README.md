# Banking System Using Java

## About the Project
This is a simple console-based banking application developed using Java. It allows users to check their balance, deposit money, and withdraw money.

## Features
- Check account balance.
- Deposit money.
- Withdraw money.
- Validate transaction amounts.
- Prevent withdrawals exceeding the available balance.
- Exit the application safely.

## Technologies Used
- Java
- Scanner class
- Switch-case
- While loop
- Conditional statements

## How to Run
1. Install the Java JDK.
2. Save the source code as `Main.java`.
3. Open a terminal in the project folder.
4. Compile using `javac Main.java`.
5. Run using `java Main`.

## Learning Outcomes
This project demonstrates Java user input, loops, conditional logic, and basic transaction calculations.
